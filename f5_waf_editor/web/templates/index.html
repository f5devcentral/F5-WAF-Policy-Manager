Snort Rule Assistant & Keyword Reference

Syntax guide and 1-click templates for F5 WAF for NGINX user-defined signatures

10 Official F5 WAF Snort Rule Templates

1. String Match (Case-Insensitive)
Official Fruits example: inspects payload for specific text string regardless of letter casing.
content:"apple"; nocase;
2. URI Path Inspection (objonly)
Targets URI path strictly, ignoring query string parameters.
uricontent:"/admin/debug.php"; objonly; nocase;
3. HTTP Header Inspection
Matches malicious strings specifically across HTTP request headers.
headercontent:"X-Attack-Payload"; nocase;
4. Bot User-Agent (useragentonly)
Narrows header inspection strictly to the User-Agent header value.
headercontent:"BadCrawler/1.0"; useragentonly; nocase;
5. Parameter Normalized (valuecontent)
Checks parameter value with evasion normalization (URL unescaping).
valuecontent:"<script>"; norm; nocase;
6. RE2 Regular Expression (Linear Time)
High-performance RE2 regex engine guaranteed against ReDoS.
re2:"/(?:eval|assert)\s*\(.*?\)/i";
7. PCRE Regular Expression
Perl-compatible regex pattern matching SQL injection keywords.
pcre:"/(union\s+select|select\s+.*\s+from)/i";
8. Hex-Escaped Specials (|20|)
Escapes spaces (|20|) and semicolons (|3B|) in binary pipe notation.
content:"SELECT|20|*|20|FROM"; nocase;
9. Relative Positioning (distance/within)
Ensures 'ADMIN' appears within 20 bytes following 'USER'.
content:"USER"; nocase; content:"ADMIN"; distance:0; within:20; nocase;
10. Response Body Leakage Check
Inspects response bodies for leaked UNIX /etc/passwd accounts.
content:"root:x:0:0:"; nocase;

Supported F5 WAF Snort Rule Keywords

Keyword Purpose & F5 Scope Syntax Example
content Searches payload body for text or pipe hex bytes (|XX|). content:"malicious";
nocase Modifies the preceding keyword to ignore letter casing. nocase;
uricontent Matches content exclusively within the normalized HTTP URI (path and query). uricontent:"/api/v1";
objonly Restricts preceding uricontent to URI path only (excludes query). uricontent:"/cmd.php"; objonly;
headercontent Searches across HTTP request headers. headercontent:"X-Forwarded-Host";
useragentonly Restricts preceding headercontent strictly to the User-Agent header. headercontent:"sqlmap"; useragentonly;
valuecontent Inspects parameter values in parameter-level signatures. Cannot be combined with uricontent. valuecontent:"../..";
norm Enables evasion normalization (URL-decoding) for valuecontent. valuecontent:"<"; norm;
re2 Google RE2 linear-time regular expression engine (safe against ReDoS). re2:"/select\s+.*?\s+from/i";
pcre Perl-Compatible Regular Expression (PCRE) pattern matching with flags. pcre:"/exec(\s|\+)+(s|x)p\w+/i";
offset / depth Limits pattern inspection window relative to the beginning of the buffer. offset:0; depth:64;
distance / within Limits pattern inspection window relative to the previous content match. distance:1; within:25;
|XX| / |XX XX| Pipe hexadecimal escaping for spaces (|20|), semicolons (|3B|), quotes (|22|). content:"eval|28 22|";
